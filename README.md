# Gesture-Controlled-Virtual-Keyboard-with-Google-Search
✨ Gesture-Controlled Virtual Keyboard ✨ Type, search, and interact without touching a keyboard! Using hand gestures captured by a camera, this system tracks finger movements to type and perform instant Google searches. 🚀 A smart, touch-free, futuristic, and hygienic way to interact using AI + Computer Vision.
🖐️ Gesture-Controlled Virtual Keyboard with Google Search
🔍 Project Overview

This project is a gesture-controlled virtual keyboard developed using HTML and browser-based technologies. It allows users to type and perform Google searches without touching a physical keyboard, using hand gestures captured through a camera. The system demonstrates a touch-free, futuristic Human–Computer Interaction (HCI) approach.

🎯 Project Purpose

The purpose of this project is to show how hand gestures can replace traditional input devices like keyboards and mice. It highlights how web technologies can be used to build intelligent, interactive systems that run directly in a browser without additional software.

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
🧠 System Concept

The system tracks hand and finger movements through the camera and maps them to a virtual keyboard displayed on the screen. Each gesture corresponds to a key selection. The typed text is automatically used as a Google search query, enabling seamless interaction.

▶️ How to Run the Project

Open the extracted project folder.

Locate the main HTML file (usually index.html).

Double-click the file or open it using a modern browser (Chrome / Edge / Firefox).

Allow camera access when prompted.

Show your hand to the camera and start interacting with the virtual keyboard.

Typed text will automatically perform a Google search.
